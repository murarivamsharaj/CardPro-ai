# Contributing to CardPro AI

We love your input! We want to make contributing to CardPro AI as easy and transparent as possible.

## Development Process

1. Fork the repo and create your branch from `develop`
2. If you've added code, add tests
3. Ensure the test suite passes
4. Make sure your code lints
5. Issue that pull request

## Code of Conduct

Please read our [Code of Conduct](CODE_OF_CONDUCT.md) before contributing.

## Any contributions you make will be under the MIT Software License

When you submit code changes, your submissions are understood to be under the same [MIT License](LICENSE) that covers the project.

## Report bugs using GitHub's [issue tracker](https://github.com/your-org/cardpro-ai/issues)

We use GitHub issues to track public bugs. Report a bug by [opening a new issue](https://github.com/your-org/cardpro-ai/issues/new).
